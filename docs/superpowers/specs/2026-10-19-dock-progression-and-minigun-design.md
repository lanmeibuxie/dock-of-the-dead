# 尸潮成长、波间强化与转轮机枪 — 设计文档

日期：2026-10-19
状态：方案已确认，待实现
关联：`2026-10-19-dock-zombie-survival-design.md`（基础玩法）

## 1. 目标

在现有无尽波次玩法上增加三层成长：

1. **僵尸逐波变强**：数值成长 + 新种类解锁。
2. **玩家波间构筑**：每波清空后三选一强化卡，可叠加，形成 build。
3. **转轮机枪**：新增第 4 把武器，提供"按住扫射"的爽快体验。

同时保持：像素画风一致、零外部素材、中文卡面、60fps。

## 2. 僵尸成长

每波生成时应用 `G.waves.scale(n)`：

| 属性 | 公式 | 说明 |
|---|---|---|
| 生命 | `1 + 0.10 * (n - 1)` | 无上限 |
| 伤害 | `1 + 0.04 * (n - 1)` | 无上限 |
| 移速 | `min(1.35, 1 + 0.012 * (n - 1))` | 35% 上限 |

- 精英波（每 5 波）再 ×1.25 生命，分数 ×2（现有规则）。
- 成长在生成瞬间写入僵尸实例（`hp/maxHp/damage/speed`），尸体与已生成僵尸不受后续波次影响。

## 3. 新僵尸种类

| 类型 | 生命 | 速度 | 伤害 | 出场 | 特性 |
|---|---|---|---|---|---|
| 疾行者 Runner | 38 | 100 | 9 | 第 3 波 | 攻击前摇 0.16s，靠速度贴身 |
| 自爆种 Bomber | 70 | 30 | 26 | 第 5 波 | 靠近玩家或死亡时引爆 |

- 预算消耗：Runner 2，Bomber 3；波次组成权重从解锁波开始加入。
- Bomber 行为：
  - 距离玩家 < 46px 时进入 `fuse`，0.7s 后爆炸；
  - 被击杀也会立即引爆炸（爆头同样触发）；
  - 爆炸半径 60：对玩家造成随距离衰减的伤害与击退；对半径 50 内僵尸造成 45 伤害，可连锁引爆其他 Bomber；
  - 爆炸产生绿色毒雾粒子、血肉、断肢、强震屏与低频爆炸音。
- 外观：Runner 使用冷灰皮肤 + 暗红衣服调色板；Bomber 使用病态黄绿调色板，引信期间身体发出脉动绿光。
- Runner/Bomber 复用现有部件骨架，仅通过调色板、速度和状态机区分，保证风格一致。

## 4. 波间强化

### 流程

```
一波清空 → 掉落补给 → 世界暂停 → 显示 3 张卡
       → 选择 1 张（点击或 1/2/3）→ 应用 → 4 秒喘息 → 下一波
```

- 新状态 `G.game.state = 'upgrade'`，期间不更新玩家/僵尸/子弹，只更新雨雾氛围与卡面。
- 每波必出；无 reroll；选卡后喘息时间由 8s 缩短为 4s。
- 卡片可重复获取并叠加等级；达到上限后不再出现在卡池。
- 稀有度权重随波次变化：
  - 第 1–2 波：普通 75% / 稀有 25% / 史诗 0%
  - 第 3–5 波：普通 60% / 稀有 32% / 史诗 8%
  - 第 6 波起：普通 45% / 稀有 40% / 史诗 15%
- 三张卡不重复。

### 卡池（18 张）

**普通（上限 8 层，灰白边框）**

| 名称 | 效果 |
|---|---|
| 伤害强化 | 所有武器伤害 +10% |
| 射速强化 | 射击速度 +8% |
| 快速换弹 | 换弹速度 +12% |
| 扩容弹匣 | 弹匣容量 +15% |
| 生命强化 | 生命上限 +15，并回复 15 |
| 移动强化 | 移动速度 +6% |
| 强力击退 | 击退力 +20% |
| 磁力拾取 | 拾取范围 +40% |
| 弹药专精 | 弹药拾取量 +25% |

**稀有（上限 5 层，青蓝边框）**

| 名称 | 效果 |
|---|---|
| 暴击强化 | 暴击率 +8%，暴击 2 倍伤害 |
| 穿透弹头 | 子弹额外穿透 1 个敌人 |
| 嗜血 | 每次击杀回复 2 点生命 |
| 稳固枪身 | 后坐力 -25%，射速 +5% |
| 战地急救 | 立即回复 40 生命，生命上限 +10 |

**史诗（上限 3 层，琥珀边框）**

| 名称 | 效果 |
|---|---|
| 死神之眼 | 暴击率 +15%，暴击伤害 +0.5 倍 |
| 弹幕风暴 | 射速 +15%，弹匣容量 +20% |
| 尸潮猎手 | 伤害 +20%，换弹速度 +10% |
| 不灭意志 | 生命上限 +30，每次击杀回复 1 点生命 |

- 暴击默认 2 倍，可与爆头 2.5 倍叠乘；暴击命中追加火花、黄色命中标记和额外震屏。
- 上限取值示例：暴击率封顶 60%，移速总加成封顶 +60%，击退封顶 +150%。
- 卡面中文、图标、稀有度边框、层数圆点；悬停高亮并自绘像素鼠标指针。

## 5. 玩家属性接入

`Player.mods`：

```
damage, fireRate, reload, mag, speed, crit, critMult,
pierce, knock, lifesteal, pickup, ammo, recoil
```

接入点：

- 伤害：开火时 `damage * (1 + damage)`，暴击再 × `critMult`。
- 射速：`Weapon.nextFire = now + rate / (1 + fireRate)`。
- 换弹：`reloadT = reload / (1 + reload)`。
- 弹匣：`magSize = round(mag * (1 + mag))`，换弹填充到新容量。
- 移速：基础 110 × `(1 + speed)`；转轮机枪旋转时另乘减速。
- 击退：传给 `Zombie.hit` 的击退系数。
- 吸血：击杀时回复。
- 拾取：判定半径 × `(1 + pickup)`；弹药拾取量 × `(1 + ammo)`。
- 后坐力：枪身后坐与准星扩散 × `(1 + recoil)`。

## 6. 转轮机枪（M134）

- 第 4 武器槽，键 `4`，滚轮循环 4 把；开局即拥有，体验优先，但弹药有限。
- 数值：伤害 9 / 射速 0.03s（约 2000 RPM）/ 弹匣 150 / 备弹 150 / 换弹 3.2s /
  扩散 0.10 / 击退 22 / 后坐 0.35 / 枪口偏移 26。
- **旋转机制**：
  - 按住左键开始旋转，`spin` 在 0.55s 内从 0 升到 1；
  - 只有 `spin == 1` 时才能开火；
  - 松开后 0.5s 内降回 0；换弹或切枪立即重置；
  - 旋转期间移动速度降低 35%。
- 手感：每发定格 12ms（爆头 25ms）且 40ms 内只触发一次；震屏每发很轻但持续；
  大量弹壳、火花、枪口光；HUD 准星下方显示旋转进度条。
- 弹药：拾取类型 `ammo_minigun`，单次 60 发；波间补给按当前武器权重掉落。
- 升级卡全部生效；高射速下粒子上限与低帧率降级继续兜底。
- 音效：新增旋转启动/停止的机械声与更高频的枪声，避免与冲锋枪混淆。

## 7. 中文像素字体

- `tools/genfont.py`：扫描 `js/*.js` 中所有 CJK 字符 + ASCII 0x20–0x7E，
  使用 Windows 宋体 12px 渲染，阈值 100 二值化，生成逐字位图。
- `js/cnfont.js`：`G.cnfont.draw(ctx, text, x, y, color, scale, align)`、
  `G.cnfont.width(text, scale)`，按字符宽度推进（中文 12/13px，ASCII 半宽）。
- 缺字回退 `?`；生成文件随源码提交，运行时零外部字体/图片。
- 卡面标题用 2 倍缩放（24px 高），名称与说明用 1 倍（12px）。

## 8. UI

- 升级界面（480×270）：
  - 顶部标题「选择强化」24px，副标题「第 N 波结束」12px；
  - 3 张卡各 132×150，水平居中，稀有度边框（灰白/青蓝/琥珀）；
  - 卡内：24×24 像素图标、名称、2–3 行说明、稀有度文字、层数圆点；
  - 底部提示「点击或按 1 / 2 / 3 选择」；
  - 自绘像素箭头指针，悬停卡片上浮并增亮。
- HUD：4 个武器槽；转轮机枪旋转条；选卡后中文提示「获得：伤害强化」1.5s。
- 暂停界面补充「4 MINIGUN」。

## 10. 测试与验收

**测试（Node）**

- 成长系数：第 1 波全 1；第 11 波生命 2.0；移速封顶 1.35。
- 波次组成：Runner 第 3 波起出现、Bomber 第 5 波起出现，预算不超支。
- 卡池：每次 3 张不重复；满级卡被排除；稀有度权重随波次变化。
- 应用：伤害/射速/弹匣叠加；生命上限与回复；暴击率与暴击倍率；穿透/吸血/拾取。
- 武器：转轮机枪弹匣 150、射速 0.03、换弹 3.2s；射速/弹匣卡生效。
- 转轮旋转：`Player.prototype.stepSpin(dt, holding)` 在按住时 0.55s 到 1，松开后回落；未满不可开火。
- 中文字体：至少覆盖全部卡面字符，缺字回退可用。

**验收（自动 + 手动）**

1. 每波僵尸生命/伤害/移速提升，肉眼可感；精英波更强。
2. 第 3、5 波开始能遇到 Runner/Bomber；Bomber 能连锁爆炸。
3. 每波清空后出现 3 张风格一致的中文卡，鼠标与数字键均可选择。
4. 卡片可叠加，HUD/伤害/移速等行为实际变化。
5. 转轮机枪：按住先转 0.55s 再开火；松开减速；弹药耗尽需换弹/拾取。
6. 转轮机枪扫射时稳定 60fps，无控制台报错。
7. `file://` 双击可玩，零外部素材。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 高射速触发过多定格/粒子导致卡顿 | 转轮机枪专用短定格 + 40ms 锁；粒子上限与 LOWFX 降级 |
| 数值成长与卡牌成长失衡 | 成长系数与卡牌幅度保持同一量级；长时模拟 5 波校验 |
| 12px 中文在低分辨率下糊 | 宋体 12px 二值化；卡面 2 倍缩放；生成后人工截图检查 |
| 转轮机枪过强 | 旋转前置、移速惩罚、弹药有限、换弹长 |
| 新僵尸破坏平衡 | Runner 低血、Bomber 有明显引信且爆炸可反噬僵尸 |
