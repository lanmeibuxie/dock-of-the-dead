# 《码头尸潮》(Dock of the Dead) — 设计文档

日期：2026-10-19
状态：已确认方案，待实现

## 1. 概述

一款在浏览器中运行的 2D 横版像素风恐怖僵尸生存游戏。玩家被困在雨夜的货运码头上，
使用枪械抵御无尽尸潮，核心体验是**重口味的射击打击感**：定格、震屏、喷血、断肢、
爆头慢动作、程序化音效。

- 单局制：无尽波次，死亡结算，按 R 重开。
- 零外部素材：所有像素图、音效在运行时程序化生成。
- 打开即玩：双击 `index.html` 即可，无需安装、无需本地服务器。

## 2. 目标与非目标

**目标**

- 命中反馈清晰可感：每一发子弹都有"打到肉"的反馈。
- 像素画面干净锐利：内部分辨率 480×270，整数倍放大，无平滑。
- 稳定的 60fps（现代笔记本）。
- 恐怖氛围：夜色、雨、雾、灯光锥、环境音。

**非目标（首版不做）**

- 剧情、多关卡、存档、成就。
- 移动端触屏、联机、排行榜后端。
- 编辑器、模组支持。

## 3. 技术方案

| 项 | 选择 |
|---|---|
| 渲染 | Canvas 2D，内部分辨率 480×270，`imageSmoothingEnabled = false`，CSS 整数倍缩放 |
| 语言 | 原生 ES2017 JavaScript，无构建步骤 |
| 模块化 | 经典 `<script>` 按序加载，全部挂在全局 `G` 命名空间（`file://` 下可用） |
| 音频 | WebAudio API 实时合成，无音频文件 |
| 物理 | 自写 AABB + 重力，不用第三方库 |
| 持久化 | 仅 `localStorage` 存最高分 |

## 4. 世界与场景

- 码头总长 2400px，单层木栈道地面，若干可站立/可跳上的木箱（单向平台）。
- 镜头横向跟随玩家，带死区与平滑，钳制在关卡范围内。
- 栈道边缘有矮栏杆；水下不可进入，落水即被"拖走"（受伤 + 复位）。
- 僵尸从左右两端走入，也会**从水里爬上栈桥边缘**（攀爬动画 + 滴水粒子）。
- 视差 3 层：远景（吊车、灯塔、雾）→ 中景（集装箱、渔网、货堆）→ 前景栈道。
- 氛围：雨丝、雾团、钠灯锥形光、动态光影（枪口火光/爆炸桶）、暗角。
- 夜晚时间不推进；波次提升时闪电 + 远处雾笛作为节奏提示。

## 5. 玩家

| 属性 | 值（初调） |
|---|---|
| 生命 | 100 |
| 移动速度 | 110 px/s（步行），无冲刺 |
| 跳跃 | 初速 -220 px/s，重力 900 px/s² |
| 受击无敌 | 0.6s |
| 近战踹击 | 冷却 1.2s，击退 220 px/s，硬直 0.35s，伤害 8 |

操作：

- `A/D` 或 `←/→` 移动，`Space` 跳跃，`Shift` 换弹
- 鼠标 360° 自由瞄准，左键射击，`1/2/3` 或滚轮切换武器
- `Q` 踹击，`Esc` 暂停，`M` 静音，`R` 死亡后重开

角色渲染采用**像素部件骨架**：头、躯干、上臂、前臂、大腿、小腿为独立像素图块，
预渲染 0–359° 旋转缓存，逐帧按状态驱动。支持瞄准跟随、后坐力位移、换弹动画，
并让断肢成为天然可用的独立实体。

## 6. 武器

| 武器 | 伤害 | 射速 | 弹匣/备弹 | 特性 |
|---|---|---|---|---|
| 手枪 | 24 | 0.22s | 12 / ∞ | 精准、无扩散、爆头率高 |
| 霰弹枪 | 12×8 弹丸 | 0.75s | 6 / 36 | 锥形扩散、强击退、近距爆发 |
| 冲锋枪 | 14 | 0.075s | 30 / 120 | 扩散大、后坐抖动强、压制力 |

- 换弹有动画与音效，可被打断（受击取消）。
- 弹药拾取按武器权重掉落；手枪备弹无限，避免完全卡死。
- 枪口火光作为 0.05s 的圆形动态光源照亮周围。
- 抛壳、准星扩散、镜头后坐全部程序化。

伤害区域倍率（所有武器通用）：头部 **2.5x** 并触发爆头演出；躯干 **1.0x**；四肢 **0.7x**
且同时累积肢体伤害（单肢累计 30 触发断肢）。霰弹枪单次命中的所有弹丸合并结算，
避免同一发打出多次定格。

## 7. 僵尸

| 类型 | 生命 | 速度 | 伤害 | 特性 |
|---|---|---|---|---|
| 游荡者 Walker | 60 | 34 px/s | 12 | 基础型，成群出现 |
| 爬行种 Crawler | 28 | 78 px/s | 8 | 低矮（难打中躯干），扑咬 |
| 壮汉 Brute | 260 | 24 px/s | 26 | 抗击退 0.35，击退减半，第二波起出现 |

- 肢体可独立断离；失去一腿转为爬行，失去持械臂降低攻击。
- 死亡方式：普通倒地（尸体保留并逐渐变暗）、爆头（头颅炸开）、断肢过多（躯干碎裂）。
- 波次预算制：`budget = 6 + wave * 3.5`，按点数购买僵尸类型；每 5 波出现精英潮。
- 波间 8 秒喘息期，刷新补给（弹药/医疗包/燃烧桶），播放雾笛。

## 8. 打击感规格（核心）

命中时按顺序叠加：

1. **Hitstop**：世界逻辑冻结 40–70ms（按武器与是否爆头），粒子/屏幕效果继续。
2. **震屏**：分级 `pistol 1.5 / smg 1.2 / shotgun 4 / 爆头 3`，带方向性衰减。
3. **白闪**：僵尸全白 0.06s，并叠加受击"抽动"偏移。
4. **定向喷血**：沿子弹方向锥形血雾 + 血滴 + 落地血渍贴花（离屏画布累积，上限 900 贴花）。
5. **击退/硬直**：按武器冲量推动，硬直期间无 AI 行为。
6. **断肢**：累计伤害阈值（单肢 30）或单发超阈值触发；断肢作为物理碎片翻滚并拖血。
7. **爆头**：头颅爆裂粒子 + 0.25s 时间缩放（0.35x）+ 骨屑 + 特殊音效。
8. **枪械反馈**：枪身位移、镜头后坐、准星扩散、抛壳、枪口光。
9. **命中标记**：准星位置闪现白色 X 与轻微放大，配合极短的“ Tick”高频音，确认命中。
10. **音效**：每发枪声随机音高/滤波；血肉命中用带通噪声爆；爆头额外加低频冲击。

玩家死亡：慢动作 + 去饱和 + 血腥特写 + 结算面板。

## 9. 音频设计（全程序化 WebAudio）

- 枪声：噪声爆发 + 低频正弦"砰"+ 快速衰减包络，霰弹枪额外低通与更长尾音。
- 血肉：短噪声 + 中频带通 + 快速 pitch drop。
- 僵尸低吼：锯齿波 + 颤音 + 低通，按距离衰减与立体声声像。
- 环境：风声（滤波噪声）、水拍栈桥、远处雾笛、雨声。
- 低血量（<30）叠加心跳（低频脉冲）。
- 主总线含压缩器防削波；`M` 静音，首次点击后解锁 AudioContext。

## 10. UI / 屏幕

- **标题屏**：游戏名、操作说明、开始提示，背景为雨夜码头空镜。
- **HUD**：左下生命条（低血量红色脉动 + 血渍 vignette）、右下弹药（弹匣/备弹）、
  顶部波次与分数、换弹进度环、武器图标。
- **波次提示**：屏幕中央像素字体 "WAVE N"，伴随闪电。
- **暂停**：半透明遮罩 + 操作说明。
- **结算**：存活波次、击杀数、爆头数、命中率、最高分（localStorage）。

## 11. 代码结构

```
index.html          画布、UI 容器、脚本加载顺序
style.css           页面居中、黑边、像素化缩放、无滚动条
js/core.js          G 命名空间、工具函数、随机数、对象池、输入
js/audio.js         程序化音效与音乐氛围
js/gfx.js           像素绘制、旋转缓存、调色板、贴花层、震屏
js/sprites.js       部件定义、武器与僵尸外观、像素字体
js/level.js         码头构建、视差、光源、雨雾
js/particles.js     血、骨屑、弹壳、火花、烟
js/entities.js      玩家、僵尸、子弹、拾取物、断肢
js/hud.js           HUD、标题、暂停、结算
js/game.js          状态机、波次导演、碰撞、主循环
```

约束：单文件 ≤ 500 行，模块间只通过 `G.*` 明确接口通信；实体不直接读输入。

## 12. 性能与调试

- 对象池化：子弹、粒子、血渍、断肢。
- 粒子上限 600，血渍上限 900，超限复用最旧。
- 离屏画布：背景层、静态道具、贴花层各一张，避免每帧重绘。
- 调试参数：`?debug=1`（碰撞盒/FPS/生成台）、`?god=1`（无敌）、`?wave=N`（跳波）。
- 目标：1080p 下 60fps；掉帧时优先降低粒子数。

## 13. 验收标准

1. 双击 `index.html` 即可游玩，无需服务器与网络。
2. 键盘 + 鼠标操作全部生效，瞄准跟手，无输入延迟感。
3. 命中僵尸时同时出现定格、震屏、白闪、喷血与音效，主观"打到了"。
4. 爆头触发放慢与头颅爆裂；持续射击可打出断肢与尸体残留。
5. 三种僵尸行为可区分，三种武器手感可区分。
6. 波次递增、补给掉落、死亡结算与重开完整可循环。
7. 画面无模糊、无锯齿拉伸；稳定 60fps。
8. 无控制台报错。

## 14. 风险与对策

| 风险 | 对策 |
|---|---|
| 手写像素部件动画不自然 | 先做单僵尸原型验证动画观感，再批量扩展 |
| 程序化音效刺耳/嘈杂 | 主总线压缩 + 音量分档 + 静音键，逐音源调参 |
| 血渍/粒子导致掉帧 | 硬上限 + 池化，掉帧时自动降级 |
| 打击感"堆料"过度导致画面混乱 | 震屏与定格分级，普通命中克制，爆头才夸张 |
